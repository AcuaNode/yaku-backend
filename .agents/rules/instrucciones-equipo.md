# Reglas de Interacción del Equipo YakuControl
- Antes de escribir código, siempre explica el patrón de diseño que vas a usar.
- Si el usuario pide crear una clase fuera de las 4 capas establecidas (Domain, Application, Infrastructure, Interfaces), rechaza la petición y guíalo hacia la capa correcta.
- Los commits deben de seguir conventional commits
- No hagas push automaticos, siempre pide confirmacion
